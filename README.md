# 文本识别项目

## 这是一个基于`Trae`开发出来的简易的日文图片识别提取文字的`django`项目

- 开发这玩意儿的初衷是为了尝试一下下智能体编程工具的强大之处，与其固步自封不如拥抱改变。
- 从`django`项目的建立到**EasyOCR**的集成，只需要几个提示词即可完成基础逻辑的搭建和效果的实现
- coder只需要熟悉所使用框架的基本运作原理和配置文件比如`Django`的MVT模式，以及settings文件中的基础配置即可上手，实现近全自动化编程。
- 美中不足的是目前仍然没办法很好的理解项目需求，特别是需要集成大量三方时，比如集成bootstrap时如果不指明的话可能会漏掉动态支持那个js文件，需要手动检查，然后就是需要手动创建基本的项目结构，比如templates等，还有就是启动运行等需要指令操作在控制台，比如`python manage.py runserver`不如Pycharm那般方便，可以快速提取指令以及一键启动项目
- 未来会持续探索该工具，很好用，并持续更新更多的基于智能体编程的项目，并接触更多的智能体工具，比如尝试一下`coze`工作流等
